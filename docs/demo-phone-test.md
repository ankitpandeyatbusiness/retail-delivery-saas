# Demo: test it on a real phone and a computer

None of the demo screens has been looked at on a real phone yet (the server side is tested by the test suite, the screens were only checked for errors). Do this list once, in English, then the parts marked (Hindi) again with the app set to Hindi. Write down anything odd.

## A. Public demo website (a phone browser, then a computer)
1. Open the demo address in a private tab. **Welcome animation**: logo, company name, "Welcome" changes language (English, Hindi, Marathi, Gujarati, Bengali). **Skip** works. Reload: it does not play again in the same tab. (Hindi)
2. **Start the demo** opens the shop with no login. The shop is called Demo Shop and has photos.
3. Tap the **Demo** button at the top. The sheet lists Customer, Owner, Cook, Waiter, Rider, **Stories: show me around**, **I liked it: talk to us**, **Reset the demo**.
4. Terms, Privacy and About (Account page): the text names the platform, never "Demo Shop".

## B. Order, and watch it move
1. Add a dish (the **Add** button), open the cart, pick the demo address, Cash on delivery, **Place order**.
2. Open Orders. Within about a minute the steps change by themselves. When it is out for delivery, open the map: the rider pin moves towards the address. It becomes Delivered.
3. Rate it. Open a complaint with a small photo (under 1.5 MB). Try a big photo: it is refused politely.
4. Tap **Demo > Owner** (the app restarts as the owner). The new order is in the list. Tap **Accept** on a fresh order before the demo does it (it waits 20 seconds). Switch to **Cook**, then **Rider** and **Waiter**. Each panel opens and shows the demo shop's own people.
5. **Demo > Reset the demo > Reset**: the orders go back to the start; you stay signed in.

## C. Stories
1. Open **Stories**. Switch **Show me around** off: the cards disappear. Switch on.
2. Start **Order your first meal**: step 2 circles the Add button; tapping it moves on. Start **Run your shop**: it asks to become the Owner; step 2 circles Accept. Start **The kitchen**: circles Start cooking.
3. Finish **Full tour**: the "Did you like the demo?" form opens. Fill name, shop name and a number. In the superadmin app **More > Demo leads** shows it, with Call, Mark called and a note, and you got a notification.
4. (Hindi) The story texts and the form are in Hindi. Also try Marathi, Gujarati and Bengali. Bhojpuri shows Hindi.

## D. Looks and desktop
On the computer, open the demo address at full width: the sidebar layouts of owner, cook, waiter and rider show. Change the shop's light and dark look in the superadmin app (Branding): the demo stays readable in each.

## E. Private demo login
1. More > Demo login: set a number and OTP. In ANY shop's app (your own, not the demo), type that number: no SMS comes; the OTP opens the shop as a new person with the **Demo** button. Try to place an order: it is refused with "This is a demo".
2. Change the OTP and remove it: the old OTP stops working.

## F. QR codes
1. More > QR codes: the demo code shows. Download PNG, SVG and PDF; open each. Scan the PNG with a phone camera: it opens the demo (through the short /q/demo address).
2. Pick a shop with dine in, switch the logo on, download **All tables (PDF sheet)**. Scan a table code on a phone **without** the app, with the Play Store link filled: **Open in the store** and **Continue in browser** appear. With the link empty: the website opens.
3. Install from the store link, sign in: the table is set by itself (Android). On an iPhone, scan again after installing.
